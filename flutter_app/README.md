# تطبيق منصة قلب العلم التعليمية (Flutter Android & iOS)

تطبيق الهاتف الذكي الرسمي لمنصة قلب العلم التعليمية، مصمم خصيصاً لطلاب الثانوية العامة ودفعة 2027 بواجهة داكنة مريحة للعين، وقائمة سريعة، وتركيز كامل على آخر درس توقف عنده الطالب مع مزامنة فورية لقاعدة بيانات المنصة.

---

## 🌟 مميزات التطبيق

1. **واجهة داكنة متقدمة (Ultra Dark Theme)**: تصميم فخم يعتمد على درجات الأسود النقي والرمادي الداكن (`#0A0E17` و `#121824`) مع لمسات زمردية وذهبية تقلل من إجهاد العين أثناء المذاكرة الطويلة.
2. **قائمة جانبية سريعة (QuickDrawer)**: تنقل فوري وسلس بين الكورسات، والامتحانات، والمحفظة، ورابط مباشر للتواصل مع المعلمين وإدارة المنصة عبر واتساب.
3. **تركيز الصفحة الرئيسية على آخر درس**: بطاقة رئيسية في واجهة التطبيق ترصد تلقائياً آخر فيديو شاهده الطالب ونسبة الإنجاز والوقت الدقيق بالثواني، مع زر استئناف مباشر بنقرة واحدة.
4. **مزامنة فورية مع قاعدة بيانات الموقع (Real-Time REST APIs)**:
   - عند تسجيل الدخول، تظهر فوراً جميع الكورسات المفعلة للطالب على موقع الويب.
   - عند حل أي امتحان في التطبيق، تُحسب النتيجة وتُسجل فوراً في لوحة تحكم المعلم ولوحة الإدارة على الموقع.
   - عند إيقاف أو متابعة أي فيديو، يُحدث موضع المشاهدة في قاعدة البيانات فوراً.

---

## 🚀 متطلبات التشغيل

- **Flutter SDK**: الإصدار 3.0.0 فما فوق
- **Dart SDK**: الإصدار 3.0.0 فما فوق
- محاكي أندرويد (Android Emulator) أو جهاز هاتف متصل بوضع USB Debugging، أو نظام macOS لتشغيل محاكي iOS.

---

## 🛠️ خطوات التشغيل والبناء

### 1. تثبيت الحزم
```bash
cd flutter_app
flutter pub get
```

### 2. ضبط رابط الخادم (API URL)
في ملف `lib/config/api_config.dart`، قم بضبط عنوان السيرفر:
```dart
// للتجربة على المحاكي (Android Emulator):
static const String baseUrl = 'http://10.0.2.2:3000/api/mobile';

// للتجربة على هاتف حقيقي عبر نفس شبكة الواي فاي:
static const String baseUrl = 'http://192.168.1.X:3000/api/mobile';

// للإنتاج مع النطاق الفعلي:
static const String baseUrl = 'https://your-domain.com/api/mobile';
```

### 3. تشغيل التطبيق في وضع التطوير
```bash
flutter run
```

### 4. بناء ملف التثبيت النهائي للأندرويد (APK)
```bash
flutter build apk --release
```
سيكون ملف الـ APK جاهزاً في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

### 5. بناء تطبيق الآيفون (iOS)
```bash
flutter build ipa --release
```

## 📡 واجهات الاتصال المربوطة (REST APIs)

| النقطة (Endpoint) | الطريقة | الوظيفة |
| :--- | :---: | :--- |
| `/api/mobile/login` | `POST` | تسجيل دخول الطالب وربط الجهاز والتحقق من كلمة المرور |
| `/api/mobile/dashboard` | `GET` | جلب بيانات الرئيسية، وآخر درس توقف عنده، والإحصائيات |
| `/api/mobile/courses` | `GET` | استعراض جميع الكورسات مع حالة التفعيل لكل كورس |
| `/api/mobile/courses/:id` | `GET` | جلب فصول ودروس وفيديوهات واختبارات الكورس |
| `/api/mobile/progress/update` | `POST` | تحديث موضع مشاهدة الفيديو ونسبة التقدم في قاعدة البيانات |
| `/api/mobile/exams/submit` | `POST` | تصحيح الامتحان وحفظ النتيجة في لوحة التحكم وقاعدة البيانات فوراً |
| `/api/mobile/student/submissions` | `GET` | سجل امتحانات الطالب ونتائجه السابقة |
